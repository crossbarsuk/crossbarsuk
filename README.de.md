## Wir machen nur eines: Automotive

Autohäuser, Werkstätten, Teilehändler, Wohnmobil- und Caravan-Betriebe, Nutzfahrzeughändler und Hersteller – sonst niemand. Keine Restaurants, keine Arztpraxen.

Begonnen haben wir mit echten Cockpits: fahrzeugspezifischen Dekoren für Armaturenbretter. Heute betreiben wir unseren eigenen internationalen PrestaShop-Multishop. Jede Leistung, die wir anbieten, musste zuerst in unserem eigenen Shop funktionieren – mit echten Produkten, echten Bestellungen, echten Bots und echten Fristen.

## Unsere Spielregeln

| | |
|---|---|
| ✅ | **Keine erfundenen Erfolgszahlen** |
| ✅ | **Keine Rankinggarantien** – Positionen kann niemand ehrlich versprechen |
| ✅ | **Keine Zusatzarbeiten ohne Ihre Freigabe** |
| ✅ | **Fremdkosten vorab und ohne Aufschlag** – Server und Lizenzen zahlen Sie direkt |
| ✅ | **Ihre Daten und Konten gehören Ihnen** – Domain, Shop, Google, Server |

